H3z0 Nameplates 0.1.6 - Forever and Midnight

Install
Place the H3z0Nameplates folder in the Interface/AddOns folder of your
WoW installation. The same folder works on World of Warcraft: Forever
and on retail (Midnight).

Settings
Click the HNP minimap button or type /hnp, /h3z0np or /h3z0nameplates in-game.
Drag the minimap button to move it.

Extra settings windows (buttons in the settings window)
SIZES: sliders for bar width and height, text sizes, aura icons,
combo points and markers.
FRIENDLY: H3z0 style on friendly plates, friendly NPC plates on/off, friendly NPCs name only (text only)
(off by default), name only for friendly players, friendly size, and
optional separate bar and text sizes for friendly plates.
TARGET & THREAT: target glow colour, target size, fading of the other
plates while you have a target, and the threat border mode.

Profiles and layout settings are stored in H3z0NameplatesDB.
Language: English.

DoesItDiePlus
With DoesItDiePlus and its DoTInfo module enabled, the nameplates show a
gold marker for remaining DoT damage and a skull for lethal damage.
For CastPrediction on these nameplates, enable its nameplate display and
run /upt frame plate H3z0NameplatesHealthBar once.
